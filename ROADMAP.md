# Folio — Roadmap развития

> Платформа для абитуриентов, поступающих за рубеж. Конструктор портфолио (Common App–style) + честный AI-фидбек + реальные шансы поступления + база олимпиад/конкурсов.
> Стек: Next.js 16 · React 19 · Firebase (Firestore + Auth) · Google GenAI · Vercel.

---

## Где мы сейчас (baseline)

**Работает:**
- Онбординг-опрос (`/start`) → конструктор портфолио (`/portfolio`)
- AI-фидбек и переписывание записей (цепочка Groq → OpenRouter → Gemini)
- Честные шансы поступления по 40 вузам (`/universities`, hard-cap ~25% у топов)
- База из 38 олимпиад/конкурсов/программ (`/discover`)
- Хранение: LocalStorage + опциональный Firestore-sync, вход через Google
- GA4 подключён

**Главные ограничения / долги:**
- Gemini-аккаунт ограничен `AQ.`-ключами (~20 запросов/день) → нельзя полагаться на Gemini
- Данные живут в LocalStorage-first → нет надёжных аккаунтов, портфолио привязано к устройству
- Нет rate-limit / защиты на `/api/*` (риск абуза и слива квоты провайдеров)
- Нет монетизации (золотой accent зарезервирован под Premium, но не используется)
- Шансы и рекомендации не объясняют источник данных → вопрос доверия

**North Star metric:** % пользователей, которые довели портфолио до готового и **сделали хотя бы один «следующий шаг»** (записались на олимпиаду / улучшили запись / скачали PDF). Это связывает ценность продукта с реальным поступлением.

## Phase 0 — Надёжность и доверие (2 недели)
*Цель: продукт не падает и ему верят.*

- [ ] **Стабилизировать AI.** Groq — основной провайдер (быстрый, щедрые лимиты), Gemini убрать из горячего пути. Добавить кэш ответов (по хешу профиля) в Firestore, чтобы одинаковые запросы не жгли квоту.
- [ ] **Rate-limit на `/api/enhance` и `/api/feedback`** (по IP / по пользователю). Без этого один бот выжигает всю дневную квоту.
- [ ] **Прозрачность шансов.** Под каждым процентом — «на основе acceptance rate + mid-50% SAT/GPA школы». Явный disclaimer «оценка, не гарантия».
- [ ] **Funnel-аналитика.** События GA: start → portfolio_started → feedback_viewed → next_move_clicked. Понять, где отваливаются.
- [ ] **Пустые состояния и загрузки.** Спиннеры, ошибки провайдера («попробуй ещё раз»), а не белый экран.

## Phase 1 — Глубина продукта (1 месяц)
*Цель: Folio делает то, за что реально благодарят — эссе и сильные формулировки.*

- [ ] **AI-коуч по эссе / personal statement.** Самая ценная часть заявки. Разбор структуры, «показывай, а не рассказывай», версия «до/после» без выдумывания фактов.
- [ ] **Activity-rewriter с before/after.** Уже частично есть в `enhance` — вынести в явный UX: слева «Started a club» → справа сильная строка с impact.
- [ ] **Улучшить модель шансов:** учёт intended major, ED/EA vs RD, расширить до 80–100 вузов. Добавить UK-специфику (personal statement, A-levels) и Канаду.
- [ ] **Экспорт в PDF** — «Common App preview» портфолио. Даёт ощущение готового артефакта + вирусный share.
- [ ] **Разбор пробелов → конкретика.** Каждый gap = кнопка «что сделать» → ведёт в `/discover` с уже применёнными фильтрами.

## Phase 2 — Аккаунты, удержание, сеть (2–3 месяца)
*Цель: пользователь возвращается и не теряет данные.*

- [ ] **Полноценные аккаунты.** Email magic-link + Google. Портфолио следует за пользователем между устройствами (сейчас LocalStorage-first — переехать на Firestore-first с локальным кэшем).
- [ ] **Роль «Counselor / Mentor».** По аналогии с LUMO («Я психолог») — отдельный вход для менторов/родителей: смотреть портфолио ученика, комментировать. Открывает B2B2C.
- [ ] **Discover → 200+ возможностей + календарь дедлайнов.** Напоминания на email за N дней. Это возвращает людей в продукт по расписанию.
- [ ] **Прогресс и стрики.** Completeness-ring уже есть — превратить в еженедельные цели («добавь 1 honor», «улучши 2 activity»).
- [ ] **Локализация под СНГ/Казахстан.** Русский интерфейс (продукт сейчас на англ.), локальные возможности: Bolashak, республиканские олимпиады, KZ-стипендии. Совпадает с позиционированием поста «· KAZAKHSTAN».

## Phase 3 — Рост и монетизация (3–5 месяцев)
*Цель: первые деньги и органический приток.*

- [ ] **Freemium.** Free: портфолио + базовый AI-фидбек (лимит N/день) + шансы. **Premium (золотой accent):** безлимитный AI, глубокий разбор эссе, экспорт PDF, расширенный список вузов, календарь-напоминания, counselor-доступ.
- [ ] **SEO-движок на `/discover`.** Каждая олимпиада/программа = отдельная страница с дедлайнами и «кому подходит» → органический трафик по запросам «USACO 2026 dates» и т.п.
- [ ] **Реферальная петля.** «Пригласи друга — оба получаете неделю Premium». Абитуриенты ходят классами/чатами.
- [ ] **Контент.** Инстаграм-серия в стиле этого поста (FOLIO is here), разборы «профиль поступившего в MIT», короткие Reels про олимпиады.

## Phase 4 — Масштаб и защита (6+ месяцев)
*Цель: моат, который трудно скопировать.*

- [ ] **B2B: школы и агентства.** Дашборд для консультантов: когорта учеников, прогресс, экспорт. Продажа подписок школам/центрам подготовки.
- [ ] **Data-moat.** Анонимизированные исходы поступлений → калибровка модели шансов на реальных данных (сейчас — эвристика по acceptance rate). Со временем это точность, которую не повторить.
- [ ] **PWA / мобильное приложение.** Пуши по дедлайнам, offline-режим портфолио.
- [ ] **Расширение вертикали:** рекомендательные письма, timeline подготовки к SAT/IELTS, интеграция с Common App.

## Технический бэклог (сквозной)
- Firestore-first данные + миграция существующих LocalStorage-профилей
- Server-side кэш AI-ответов + идемпотентность запросов
- Rate-limiting и защита API-ключей (никогда не светить провайдеров на клиенте)
- Тесты на `lib/chances.js` (модель шансов — ядро доверия, регрессии недопустимы)
- Мониторинг квот провайдеров + алерт «Groq упал → OpenRouter»
- Обновление данных вузов/конкурсов (скрипт-генератор `*.generated.js` → регулярный ре-пул)

## Метрики по фазам
| Phase | Что меряем |
|-------|-----------|
| 0 | Uptime AI, % успешных feedback-запросов, стоимость на пользователя |
| 1 | % дошедших до эссе-коуча, кол-во PDF-экспортов |
| 2 | 7-day retention, % вернувшихся по напоминанию |
| 3 | Free→Premium конверсия, CAC/LTV, органический трафик из `/discover` |
| 4 | B2B-контракты, точность модели шансов vs реальные исходы |

### Приоритет №1 прямо сейчас
1. Groq как основной провайдер + кэш + rate-limit (иначе продукт нестабилен на любом трафике).
2. AI-коуч по эссе — фича, ради которой возвращаются.
3. Freemium с золотым Premium — путь к первым деньгам.
